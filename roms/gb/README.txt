Put your Game Boy ROMs (.gb) in roms/gb/, then run ./compile.sh from the main folder.
Each game lands in roms/meta/<Game>/ (or roms/pokitto/<Game>/): copy that folder as is to the root of the SD card.
Recorded play sessions are kept in roms/gb/profiles/: do not delete that folder.

Mets tes ROMs Game Boy (.gb) dans roms/gb/, puis lance ./compile.sh depuis le dossier principal.
Chaque jeu arrive dans roms/meta/<Jeu>/ (ou roms/pokitto/<Jeu>/) : copie ce dossier tel quel à la racine de la carte SD.
Les parties enregistrées sont gardées dans roms/gb/profiles/ : ne supprime pas ce dossier.
